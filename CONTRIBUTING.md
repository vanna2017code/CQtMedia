# Contributing to CQtMedia

Thank you for your interest in contributing! 🎬🤖  
We welcome improvements, bug fixes, new features, and documentation updates.

## How to Contribute
1. **Fork** the repository
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/your-feature-name

3. **Commit your changes** with clear messages:
   ```bash
   git commit -m "Add chapter bar tooltips

4. **Push** to your fork:
   ```bash
   git push orgin feature/your-feature-name

5. **Open a pull request** against the main branch.

## Guidelines:
Follow the existing coding style (Qt/C++17).
Keep commits atomic and descriptive.
Add/update documentation for new features.
Include screenshots or GIFs for UI changes.
Write tests if applicable.

## Reporting Issues
Use the GitHub Issues tab.
Provide steps to reproduce, expected behavior, and screenshots if possible.

Feature Ideas
We especially welcome contributions around:
Thumbnail previews on hover
Subtitles support (.srt)
Recommendations dock widget
Chapter markers on position slider

By contributing, you also agree to follow our [Code Of Conduct.](code_of_conduct)
